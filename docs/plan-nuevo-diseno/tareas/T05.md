# T05 · Cabecera y pie

**Objetivo:** Copia `SiteLayout`, con la cabecera, el pie, la barra mínima y el modo app.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T05
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

   Debe terminar con `VERIFICACIÓN CORRECTA`.

3. Haz commit y push:

```bash
git add packages/app/src/ui/site/site-layout.tsx
git status --short
git commit -m "feat(app): cabecera y pie del sitio público"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- `verificar.sh` termina con `VERIFICACIÓN CORRECTA`.
- El commit está subido.

## Si falla

- **`catalog.test.ts` dice que una clave sobra o falta:** comprueba que `aplicar.mjs` terminó bien. Si fue así, para.
