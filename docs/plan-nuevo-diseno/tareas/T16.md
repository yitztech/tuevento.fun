# T16 · Documentación

**Objetivo:** Actualiza `DESIGN.md`, `PRODUCT.md`, `docs/LANDING.md`, `docs/ASSETS.md` y `docs/SHADCN.md`, y borra el contrato de superficie de la portada vieja.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T16
   ```

2. Haz commit y push:

```bash
git add DESIGN.md \
  PRODUCT.md \
  docs/ASSETS.md \
  docs/LANDING.md \
  docs/SHADCN.md \
  packages/app/.impeccable/surfaces/landing-page.md
git status --short
git commit -m "docs: el sitio público en el sistema de diseño"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- El commit está subido.

## Si falla

- **El parche no encaja:** alguien cambió esos documentos. Para y avisa.
