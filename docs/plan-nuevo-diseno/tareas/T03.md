# T03 · Botones, acordeón y SVG

**Objetivo:** Añade las variantes `light`, `lg` y `round` de `Button`, el acordeón de shadcn y los SVG del sitio.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T03
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

   Debe terminar con `VERIFICACIÓN CORRECTA`.

3. Haz commit y push:

```bash
git add apps/web/public/site/backgrounds/cta-band.svg \
  apps/web/public/site/branding/logo-mark.svg \
  apps/web/public/site/decorations/balloons.svg \
  apps/web/public/site/decorations/floral-corner.svg \
  apps/web/public/site/decorations/leaf-branch.svg \
  packages/app/src/ui/accordion.tsx \
  packages/app/src/ui/button.tsx
git status --short
git commit -m "feat(app): variantes de botón, acordeón y adornos del sitio"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- `verificar.sh` termina con `VERIFICACIÓN CORRECTA`.
- El commit está subido.

## Si falla

- **`catalog.test.ts` dice que una clave sobra o falta:** comprueba que `aplicar.mjs` terminó bien. Si fue así, para.
