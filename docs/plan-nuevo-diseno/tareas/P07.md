# P07 · Documentación

**Objetivo:** `docs/PAGOS-PENDIENTES.md` cuenta los cupones, cómo probar con Stripe de verdad y qué falta para cobrar.

**Antes de empezar:** estás en la rama `feat/pagos-cupones`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs P07
   ```

2. Haz commit y push:

```bash
git add .env.example \
  README-project.md \
  docs/PAGOS-PENDIENTES.md
git status --short
git commit -m "docs: cupones y pasos para conectar Stripe"
git push origin feat/pagos-cupones
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- El commit está subido.

## Si falla

- **`pila-ci.sh api` falla una vez con `ECONNRESET`:** repítelo. Pasó una vez en el ensayo y no se reprodujo.
- **`aplicar.mjs` escribe `PARA:`:** para y avisa con el mensaje completo.
- **Una prueba falla dos veces con el mismo error:** para y avisa con el error completo. No cambies el código.
