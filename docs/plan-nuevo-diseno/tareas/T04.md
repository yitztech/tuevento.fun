# T04 · Piezas comunes

**Objetivo:** Copia las piezas pequeñas que usan las secciones. Nadie las muestra aún.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T04
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

   Debe terminar con `VERIFICACIÓN CORRECTA`.

3. Haz commit y push:

```bash
git add packages/app/src/ui/site/decorative-background.tsx \
  packages/app/src/ui/site/phone-frame.tsx \
  packages/app/src/ui/site/phone-invitation.tsx \
  packages/app/src/ui/site/photos.ts \
  packages/app/src/ui/site/rings-icon.tsx \
  packages/app/src/ui/site/section-heading.tsx \
  packages/app/src/ui/site/site-photo.tsx \
  packages/app/src/ui/site/theme-card.tsx \
  packages/contracts/src/locales/de.json \
  packages/contracts/src/locales/en.json \
  packages/contracts/src/locales/es.json \
  packages/contracts/src/locales/fr.json \
  packages/contracts/src/locales/pt.json
git status --short
git commit -m "feat(app): piezas comunes del sitio público"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- `verificar.sh` termina con `VERIFICACIÓN CORRECTA`.
- El commit está subido.

## Si falla

- **`catalog.test.ts` dice que una clave sobra o falta:** comprueba que `aplicar.mjs` terminó bien. Si fue así, para.
