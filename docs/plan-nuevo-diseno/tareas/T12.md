# T12 · Precios y legales

**Objetivo:** Precios y páginas legales entran en `SiteLayout`.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T12
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

3. Ejecuta los escenarios afectados en la pila de CI:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh sube
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh e2e "@precios|@legal|@sitio"
   node docs/plan-nuevo-diseno/herramientas/capturas.mjs /precios /privacidad /condiciones
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh baja
   ```

4. Haz commit y push:

```bash
git add packages/app/src/legal.tsx \
  packages/app/src/pricing.tsx \
  tests/e2e/features/sitio-paginas.feature
git status --short
git commit -m "feat(app): precios y legales en el sitio nuevo"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- `verificar.sh` escribió `VERIFICACIÓN CORRECTA`.
- El resumen dice `0 fallidos`.
- `capturas.mjs` no escribió `MAL`.
- El commit está subido.

## Si falla

- **Un escenario falla:** repítelo una vez. Si vuelve a fallar, para y copia el error completo.
