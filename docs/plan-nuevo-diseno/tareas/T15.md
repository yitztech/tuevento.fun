# T15 · Limpieza de CSS

**Objetivo:** Borra de `styles.css` las reglas de clases que ya nadie usa.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T15
   ```

2. Comprueba que ninguna de esas clases sigue en uso. Este comando no debe escribir nada:

   ```bash
   git grep -nE "auth-layout|auth-story|auth-heart|auth-form-wrap|auth-language|provider-page-top|landing-legal-links" -- packages apps/web/src
   ```

3. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

4. Haz commit y push:

```bash
git add packages/app/src/styles.css
git status --short
git commit -m "refactor(app): quita el CSS que dejó el sitio viejo"
git push origin feat/sitio-nuevo
```

## Hecho cuando

- El paso 2 no escribió nada.
- `verificar.sh` escribió `VERIFICACIÓN CORRECTA`.

## Si falla

- **El paso 2 encuentra algo:** para. No borres ese código.
