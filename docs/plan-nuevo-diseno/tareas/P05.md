# P05 · Cupones en la API

**Objetivo:** La API comprueba un cupón y lo aplica al abrir un pago. Es dinero: esta tarea tiene puerta de revisión.

**Antes de empezar:** estás en la rama `feat/pagos-cupones`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs P05
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

3. Ejecuta las pruebas en la pila de CI:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh sube
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh api
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh e2e "@pagos"
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh baja
   ```

4. Haz commit y push:

```bash
git add apps/api/src/controllers.ts \
  apps/api/src/payments.ts \
  apps/api/src/rate-limit.ts \
  packages/contracts/src/pricing.ts \
  services/payments-fake/server.mjs \
  tests/api/api.mjs \
  tests/api/test-api.mjs \
  tests/api/test-endpoints.mjs \
  tests/api/test-security.mjs \
  packages/contracts/src/locales/es.json \
  packages/contracts/src/locales/en.json \
  packages/contracts/src/locales/pt.json \
  packages/contracts/src/locales/de.json \
  packages/contracts/src/locales/fr.json
git status --short
git commit -m "feat(api): cupones de descuento al abrir un pago"
git push origin feat/pagos-cupones
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

5. Para y pide la revisión: un modelo más capaz, o el usuario, revisa `apps/api/src/payments.ts` con `/code-review`.
   No sigas con P06 hasta tener su visto bueno.

## Hecho cuando

- `verificar.sh` escribió `VERIFICACIÓN CORRECTA`.
- `pila-ci.sh api` escribió `API CORRECTA`.
- El resumen de los escenarios dice `0 fallidos`.
- El commit está subido y la revisión dio su visto bueno.

## Si falla

- **`pila-ci.sh api` falla una vez con `ECONNRESET`:** repítelo. Pasó una vez en el ensayo y no se reprodujo.
- **`aplicar.mjs` escribe `PARA:`:** para y avisa con el mensaje completo.
- **Una prueba falla dos veces con el mismo error:** para y avisa con el error completo. No cambies el código.
