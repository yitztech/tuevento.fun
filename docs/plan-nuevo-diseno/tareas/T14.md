# T14 · Proveedores

**Objetivo:** La búsqueda y la página de un proveedor entran en `SiteLayout`. Los filtros y las tarjetas no cambian.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T14
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

3. Ejecuta toda la suite en la pila de CI:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh sube
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh todo
   node docs/plan-nuevo-diseno/herramientas/capturas.mjs /proveedores
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh baja
   ```

4. Haz commit y push:

```bash
git add packages/app/src/provider-page.tsx \
  packages/app/src/provider-search.tsx \
  packages/contracts/src/locales/de.json \
  packages/contracts/src/locales/en.json \
  packages/contracts/src/locales/es.json \
  packages/contracts/src/locales/fr.json \
  packages/contracts/src/locales/pt.json
git status --short
git commit -m "feat(app): proveedores en el sitio nuevo"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Revisión

Para aquí y pide la revisión. Entrega las capturas de `qa-artifacts/sitio/` y compáralas con las del prototipo.
No sigas con la tarea siguiente hasta que el revisor diga que está bien.

## Hecho cuando

- `pila-ci.sh todo` escribió `TODO CORRECTO`.
- El revisor dio el visto bueno.

## Si falla

- **Un escenario `@movil` de proveedores cambia:** estas páginas también corren en las apps. Para y avisa.
