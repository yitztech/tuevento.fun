# P04 · Cupones en el panel

**Objetivo:** El administrador crea, lista y desactiva cupones en la pestaña «Cupones». El panel solo está en español: esta tarea no lleva traducciones.

**Antes de empezar:** estás en la rama `feat/pagos-cupones`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs P04
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   npm run build -w @tuevento/admin
   ```

3. Ejecuta los escenarios del panel en la pila de CI:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh sube
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh e2e "@admin"
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh baja
   ```

4. Haz commit y push:

```bash
git add apps/admin/src/coupons.mjs \
  apps/admin/src/coupons.test.mjs \
  README-project.md \
  apps/admin/src/db.mjs \
  apps/admin/src/server.mjs \
  apps/admin/src/stats.mjs \
  apps/admin/src/web/admin.component.html \
  apps/admin/src/web/admin.component.ts \
  apps/admin/src/web/api.ts \
  apps/admin/src/web/styles.css \
  compose.prod.yml \
  tests/e2e/features/admin.feature \
  tests/e2e/steps/admin.js
git status --short
git commit -m "feat(admin): pestaña de cupones para crearlos y desactivarlos"
git push origin feat/pagos-cupones
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- `verificar.sh` escribió `VERIFICACIÓN CORRECTA`.
- El resumen de los escenarios dice `0 fallidos`.
- El commit está subido.

## Si falla

- **`pila-ci.sh api` falla una vez con `ECONNRESET`:** repítelo. Pasó una vez en el ensayo y no se reprodujo.
- **`aplicar.mjs` escribe `PARA:`:** para y avisa con el mensaje completo.
- **Una prueba falla dos veces con el mismo error:** para y avisa con el error completo. No cambies el código.
