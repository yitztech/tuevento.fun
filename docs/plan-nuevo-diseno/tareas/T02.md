# T02 · Fuentes, tokens y site.css

**Objetivo:** La base visual del sitio: Great Vibes, los tokens de `.site-surface` y las utilidades. La web no cambia todavía.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T02
   ```

2. Actualiza las dependencias:

   ```bash
   npm install
   ```

3. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

   Debe terminar con `VERIFICACIÓN CORRECTA`.

4. Haz commit y push:

```bash
git add apps/web/src/main.tsx \
  package-lock.json \
  packages/app/package.json \
  packages/app/src/site.css \
  packages/app/src/styles.css \
  packages/app/src/tailwind.css
git status --short
git commit -m "feat(app): tokens y fuentes del sitio público"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Hecho cuando

- `verificar.sh` termina con `VERIFICACIÓN CORRECTA`.
- El commit está subido.
- Las páginas se ven igual que antes.

## Si falla

- Si `npm install` deja cambios en otros paquetes además de `@fontsource/great-vibes`, para.
- **`catalog.test.ts` dice que una clave sobra o falta:** comprueba que `aplicar.mjs` terminó bien. Si fue así, para.
