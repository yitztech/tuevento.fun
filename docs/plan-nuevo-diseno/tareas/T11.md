# T11 · Marco del acceso

**Objetivo:** Las seis pantallas de acceso usan el marco nuevo. Los formularios no cambian. Estas pantallas también corren en las apps.

**Antes de empezar:** estás en la rama `feat/sitio-nuevo`, la tarea anterior terminó y su commit está subido.
Lee las «Reglas para quien implementa» de `docs/plan-nuevo-diseno/README.md`.

## Pasos

1. Aplica la tarea:

   ```bash
   node docs/plan-nuevo-diseno/herramientas/aplicar.mjs T11
   ```

2. Comprueba:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/verificar.sh
   ```

3. Ejecuta toda la suite en la pila de CI:

   ```bash
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh sube
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh todo
   node docs/plan-nuevo-diseno/herramientas/capturas.mjs /acceso /registro /recuperar-contrasena
   bash docs/plan-nuevo-diseno/herramientas/pila-ci.sh baja
   ```

4. Ejecuta las pruebas de las apps, una plataforma tras otra. Tardan unos 40 minutos:

   ```bash
   docker compose --profile mobile up -d mobile-tls
   npm run e2e:movil
   ```

5. Haz commit y push:

```bash
git add packages/app/src/account.tsx \
  packages/app/src/ui/site/auth-shell.tsx \
  packages/contracts/src/locales/de.json \
  packages/contracts/src/locales/en.json \
  packages/contracts/src/locales/es.json \
  packages/contracts/src/locales/fr.json \
  packages/contracts/src/locales/pt.json \
  tests/e2e/features/sitio-acceso.feature
git status --short
git commit -m "feat(app): marco nuevo de las pantallas de acceso"
git push origin feat/sitio-nuevo
```

`git status --short` no debe mostrar en verde nada fuera de esa lista.

## Revisión

Para aquí y pide la revisión. Entrega las capturas de `qa-artifacts/sitio/` y compáralas con las del prototipo.
No sigas con la tarea siguiente hasta que el revisor diga que está bien.

## Hecho cuando

- `pila-ci.sh todo` escribió `TODO CORRECTO`.
- `e2e:movil` pasó en Android e iOS. Si un escenario solo pasa al reintentar, dilo en la entrega.
- El revisor dio el visto bueno.

## Si falla

- **Android falla por tiempo y `qemu` usa mucha CPU:** apaga el emulador con `adb emu kill`, ejecuta
  `bash scripts/mobile-test-android.sh` y repite `npm run e2e:android`. Si vuelve a fallar, para.
- **`test:password` falla:** mira `$TMPDIR/test:password.log` y para.
